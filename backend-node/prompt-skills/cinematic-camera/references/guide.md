# 镜头设计执行合同

## 先确定镜头任务

每个镜头先回答：观众此刻必须看到什么、人物目标是什么、情绪发生什么变化、镜头结束时画面要留下什么结果。没有明确任务时，不要先选择炫技运镜。

## 六项镜头参数

1. **景别/距离**：环境信息、人物关系、表情或细节哪一项优先。
2. **相机高度**：视线高度、中性观察、俯视压迫或仰视权力必须有叙事理由。
3. **观察方位**：正面、侧面、背面或环绕角度决定人物关系和空间可读性。
4. **焦段感**：广角强调空间与速度，标准焦段保持自然，长焦压缩空间并隔离主体。
5. **构图**：主体位置、视线空间、运动空间、前中后景和画面轴线。
6. **运动路径**：写清起点、过程、速度变化、主体画面位置变化、终点和停止原因。

## 运动复杂度

- 单镜头最多两个主要运动轴；第三种变化只能作为轻微修饰。
- 推近用于发现、压迫、亲密和情绪加强；拉远用于揭示、孤立和收束。
- 横移、摇摄和跟拍用于建立空间关系或连续动作，必须预留运动方向前方空间。
- 环绕只在主体轮廓、背景层次和动作稳定时使用；近景人物避免高速大角度环绕。
- 变焦、旋转、甩镜和复杂复合运镜必须服务明确转折，不能同时堆叠。

## 连续性

- 相邻镜头避免无意义地重复相同景别、机位和强度。
- 保持视线方向、人物左右关系、运动方向和轴线；跨轴必须通过中性镜头或可见移动解释。
- 镜头起点继承上一镜头结果，镜头终点为下一镜头提供动作、视线、构图或声音出口。

## 输出检查

- 镜头词是否可以被摄像机和主体真实执行。
- 是否只写了运镜名称，没有主体、路径和结果。
- 景别和焦段是否与人物动作、空间大小冲突。
- 运镜是否会导致近景面部、肢体、背景或透视漂移。
- 镜头终点是否具有可见结果，而不是运动到一半结束。
