# 电影镜头语言

将叙事目标转换为可执行的景别、机位、焦段感、构图和运镜路径。核心方法来自相机四维编码体系：Z 轴控制距离与信息量，Y 轴控制高度与权力关系，X 轴控制观察方位与空间立体感，F 层控制焦段、身份叙事和构图几何。

本能力包不是镜头词库堆叠器。它要求每个镜头说明选择原因、起点、运动过程、主体在画面中的变化、停止位置和可见结果，并在输出前检查轴线、视线、运动方向、近景人脸风险和复合运镜冲突。

阶段资料：

- `guide.md`：镜头设计入口、执行合同和检查流程。
- `相机四维编码`：完整四维编码、运镜词典、情绪映射、组合模式和故障排查。
- `cinematic-镜头与美学词汇库`：速度、情绪、风格、画质、光影和大气词汇。
