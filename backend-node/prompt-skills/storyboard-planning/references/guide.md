# 分镜与场景调度执行合同

## 分镜拆解

先按叙事节拍和完整动作链拆镜，不按句号或固定秒数机械拆分。每个镜头写明人物目标、初始状态、动作过程、可见结果、情绪变化和镜头出口。

## 空间合同

- 建立场景的入口、出口、主要家具、光源、前中后景和人物活动区。
- 多人场景记录左右站位、前后距离、朝向、视线、遮挡和轴线。
- 人物移动必须经过可见路径；不能在相邻镜头无解释地换边、瞬移或改变姿态。
- 道具记录初始位置、持有者、移动过程和最终位置。

## 多格分镜板分类

1. **连续动作链**：同一人物、同一场景、同一时间线，格子是动作切片。合并为少量动作阶段，用连续跟拍或动势匹配还原。
2. **顺承场景**：人物一致，时间或地点自然递进。按格生成并用硬切、声音桥或光线变化连接。
3. **独立场景蒙太奇**：场景和机位跳跃，但有共同人物或情绪。用情绪母题、语义转场和首尾呼应建立统一性。

## 分镜板陷阱

- 网格线、编号、留白和界面不是最终画面元素，生成时必须明确输出全屏单镜头。
- 格数不是模式选择的唯一依据，动作关系和单片段信息容量更重要。
- 不要把每格都等长处理；关键动作、对白和反应需要不同时间。
- 多格参考只提供视觉和时序信息，不能覆盖剧本事实、人物身份和项目画幅。

## 镜头序列检查

- 是否连续三个镜头使用相同景别和强度。
- 是否有建立空间、推进动作、确认结果和反应镜头。
- 每个镜头的初始状态是否继承上一镜头结果。
- 轴线、视线和运动方向是否连续；跨轴是否被解释。
- 是否给首尾帧和视频提示词留下明确、可视化的状态合同。
