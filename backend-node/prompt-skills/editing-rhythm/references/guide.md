# 动作与剪辑节奏执行合同

## 节拍拆解

每个镜头至少识别：准备、触发、动作、结果、反应。不是每个镜头都需要五项，但动作镜头不能缺少结果，对白镜头不能缺少听者反应。

## 时长分配

- 建立空间需要阅读时间；不要在观众看懂前切走。
- 对白按语速、停顿和反应分配，不用平均秒数。
- 高速动作保留起势、命中/转折和结果，避免从开始直接跳到结束。
- 情绪镜头可以慢，但必须有呼吸、眼神、光影或环境微动。
- 相邻镜头长度和强度应有变化，除非刻意制造机械重复感。

## 剪辑接点

- 动作接点：在相同动势或动作峰值切换。
- 视线接点：先给凝视，再切到目标或反应。
- 声音接点：对白尾音、脚步、撞击、环境音或音乐拍点跨镜连接。
- 构图接点：用相似形状、颜色、主体位置或运动方向做匹配剪辑。

## AI 素材风险

- 片段开头和结尾可能存在姿态稳定过程，生成时应给明确初始/最终状态，剪辑时允许修掉不稳定帧。
- 色彩和曝光漂移优先通过统一光源与风格合同预防，再在后期匹配。
- 动作断裂使用遮挡、动势匹配、反应镜头或环境桥接，不用花哨转场掩盖空间错误。
- 局部畸变不要长时间停留，可在不损失叙事信息的前提下调整剪辑点。

## 输出检查

- 每段是否有明确戏剧任务和可见结果。
- 节奏变化是否来自剧情与情绪，而不是机械加速。
- 对白、动作、运镜和声音是否互相争抢导致信息过载。
- 镜头出口是否能自然连接下一镜的动作、视线、声音或构图。
