# 多片段长视频规划策略

## 核心原理

当故事所需动作、对白或场景变化超过当前模型一次生成可稳定承载的容量时，采用**分段生成 + 连续性桥接 + 后期拼接**。这里把模型支持的稳定单片段时长记为 `L`，具体数值由厂商适配层决定，创作 Skill 不假设固定上限。

长视频的成败主要取决于五件事：

1. **结构**：先建立世界和人物目标，再推进变化，最后给出可见结果与情绪收束。
2. **锁定**：每段都重复必要的角色、场景、画风、时代和空间关系，不依赖模型自行记忆。
3. **节奏**：根据剧情使用慢—快—慢、海浪式、心跳式或其他明确节奏曲线。
4. **衔接**：上一段的最终状态必须成为下一段的初始状态，不能只写“继续”。
5. **声音**：对白、环境音和音乐跨段连续，声音桥通常比视觉转场更能消除拼接感。

## 三段式叙事骨架

无论题材是剧情、广告、动作、科幻还是人物短片，先把整段内容划成三个功能层，再决定每层包含多少生成片段。

### 第一层：建立世界（约 0–30%）

- 交代空间、人物、目标、关系或产品。
- 信息密度偏低，先让观众看懂谁在哪里、想做什么。
- 优先使用建立镜头、稳定机位或有明确终点的缓慢运动。
- 结尾必须埋下推动下一层的动作、视线、声音或空间出口。

### 第二层：变化推进（约 30–75%）

- 冲突、动作、信息或视觉变化持续升级。
- 每个片段只承担一个主要戏剧任务，复杂动作拆成可验证的阶段。
- 镜头强度可以提高，但相邻片段的运动轴和景别要形成递进，不能无理由重复。
- 对白镜头必须给反应空间，不能只安排说话者而没有听者结果。

### 第三层：结果与收束（约 75–100%）

- 让核心动作出现可见结果，让情绪或信息落地。
- 节奏回稳，减少新概念，不在最后片段突然引入无关人物或场景。
- 最后画面应具有构图终点、表情终点、道具终点或空间出口，可用于片尾或下一场衔接。

## 全局连续性合同

长视频规划前先建立一份所有片段共享的合同。每个镜头只重复与本段有关的条目，但不得改写其事实。

### 角色锁定

- 角色 ID、姓名、年龄感、面部身份锚点保持一致。
- 服装、发型、妆容和随身道具只有在剧本明确发生变化时才能改变。
- 记录每段结束时人物的左右站位、朝向、姿态、表情、手中道具和视线目标。
- 多人场景维护轴线和视线方向；若跨轴，必须安排中性镜头或可见的空间移动。

### 场景锁定

- 场景时代、建筑结构、入口出口、主要家具和光源方向保持一致。
- 建立简化空间图：前景、中景、背景，人物活动区，镜头可移动区。
- 日夜、天气或灯光变化必须通过画面中的时间推进体现，不能跨段突变。

### 视觉风格锁定

- 固定写实/动画程度、色彩主调、对比度、材质、镜头质感、颗粒和画幅。
- 风格词使用同一组核心表达，不在后续段落换成近义但会改变渲染结果的词。
- 允许情绪段落改变亮度或色温，但需说明变化起点、过程和终点。

## 分段规则

1. 先按叙事动作和场景边界切分，再用 `L` 检查每段是否可执行；不要先平均分秒数。
2. 单片段包含一个主动作链，复杂动作最多保留两个主要运动轴。
3. 每段写明：初始状态、触发动作、过程、可见结果、镜头终点、声音终点。
4. 相邻两段共享一个明确桥接状态：人物姿态、道具位置、环境运动、光影或声音至少锁定两项。
5. 若一段需要模型同时完成换场、换装、多人高速动作和复杂运镜，应继续拆分。
6. 对生成不稳定的动作，宁可增加桥接镜头，也不要依赖一句“自然过渡”。

## 四种衔接方法

### 1. 尾帧状态延续

最稳妥的剧情连续方法。上一段结尾写成可以持续的状态，下一段开头先复述这一状态，再进入新动作。

```text
上一段终点：角色 A 位于画面左侧，右手按住桌面文件；角色 B 位于右侧，视线停在文件上；窗外冷光从右后方进入。
下一段起点：保持相同人物身份、左右站位、文件位置和右后方冷光。前段先保留呼吸、眼神与手指轻微动作，随后角色 A 才把文件推向角色 B。
```

### 2. 桥接镜头

在两个主要动作之间安排低风险、可持续的视觉或声音变化：

- 风吹衣角、树叶、发丝、旗帜。
- 雨水、烟雾、尘埃、蒸汽、火焰或水面波纹。
- 眼神移动、呼吸、握力变化、轻微转身。
- 光影移动、霓虹闪烁、门缝光变化。
- 脚步、雨声、机械低鸣、呼吸声或一句对白的尾音。

桥接不是无意义停顿；它要同时提供连续性证据和下一动作的启动条件。

### 3. 同构图推进

保持主体和空间关系，只让景别、动作或光线逐步变化：

- 远景建立空间 → 中景显示互动 → 近景确认结果。
- 同一机位 → 人物姿态变化 → 道具位置变化。
- 同一人物位置 → 光线或背景活动逐渐变化。

同构图推进适合对白、悬疑、产品展示和情绪累积，能显著降低跨段漂移。

### 4. 动势匹配与声音桥

- 上一段向右运动的主体，下一段应从兼容的方向继续，除非明确设计反向冲击。
- 用形状、颜色、动作速度或声音做 match cut，让换场具有视觉逻辑。
- 新场景的声音可以在画面切换前提前进入，旧场景声音可以延续到新画面后再淡出。

## 节奏与信息密度

不要把每个片段都写成同样长度和强度。先为每段标记情绪强度、对白密度、动作复杂度和视觉新信息，再分配时长。

- 建立镜头需要空间阅读时间。
- 对白需要说话、听取和反应三个节拍。
- 高速动作要给起势、命中/转折和结果，不要只有过程。
- 视觉奇观可以短而强，但必须留出辨认主体和结果的时间。
- 情绪收束可以减速，但画面仍需保留呼吸、视线、光影或环境微动。

## 声音连续性

每段至少记录以下声音状态：

- 当前环境底噪及空间混响。
- 对白或旁白是否跨段，最后一个字落在哪个画面动作上。
- 音乐节拍、配器和强度变化。
- 用于转场的关键音效及其提前或延后时间。

同一场景的环境音不能在切段处突然消失。对白跨段时必须保持角色音色、距离感和空间混响一致。

```markdown
# 多片段视频规划

- 场景空间与时代：...
- 画风、色调、材质和画幅：...
- 轴线、运动方向和声音基准：...

## 节奏曲线
- 建立世界（约 0–30%）：...
- 变化推进（约 30–75%）：...
- 结果收束（约 75–100%）：...

## 片段 1
- 戏剧任务：...
- 初始状态：...
- 动作过程：...
- 可见结果：...
- 运镜起点/路径/终点：...
- 声音：...
- 尾帧连续性快照：...

## 片段 2
- 承接上段状态：...
- 本段新增变化：...
- 动作过程与结果：...
- 运镜起点/路径/终点：...
- 声音桥：...
- 尾帧连续性快照：...

## 后续片段
- 按相同结构继续，直到核心动作和情绪得到结果。

## 拼接检查
- 角色身份、服装、左右站位、道具和光源是否一致。
- 每个切点是否有画面或声音桥。
- 是否存在重复叙事、无结果动作或突然新增信息。
```

## 失败模式与修复

### 人物变脸或换装

原因通常不是形容词不够，而是没有重复身份锚点或上一段尾帧状态。修复时引用同一角色素材，并把身份、服装、姿态和站位写成事实，不让模型重新设计。

### 场景跳变

补充空间图、入口出口、主体相对位置和固定光源；下一段第一句话先复述上一段终点，再写新增动作。

### 拼接明显

检查切点两侧的主体方向、运动速度、景别和环境音。优先使用微动作桥、声音桥或同构图推进，不用无依据的闪白和花哨转场掩盖事实冲突。

### 节奏平均而乏味

重新标记每段戏剧任务和情绪强度，删除重复建立镜头，把时间留给转折、反应和可见结果。节奏变化来自信息与情绪变化，不是机械加速。

### 后段画风漂移

把全局视觉合同复制到每个片段，保持核心风格词、色温、材质和镜头质感一致；只允许与剧情相关的渐进变化。
