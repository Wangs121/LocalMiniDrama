# 长视频连续性执行合同

## 先建立全局合同

- 剧情事实、人物身份、关系和目标。
- 角色外貌、服装、发型、随身道具和允许变化条件。
- 场景时代、空间图、主要光源、天气和时间。
- 画风、色调、材质、画幅、镜头质感和声音基准。
- 轴线、运动方向和每个场景的入口出口。

## 再按戏剧任务分段

每段只承担一个主要任务：建立、推进、转折、高潮、结果或收束。分段由动作复杂度和模型单片段容量共同决定，不平均切割时间。

每段必须写：

1. 承接上一段的初始状态。
2. 本段触发动作和人物目标。
3. 动作过程与镜头路径。
4. 可见结果和情绪变化。
5. 声音状态。
6. 尾帧连续性快照。

## 桥接优先级

1. 尾帧状态直接延续。
2. 同构图中的人物、道具或光线推进。
3. 动势匹配、视线匹配或形状匹配。
4. 环境微动和声音桥。
5. 只有剧情需要时才使用明显转场效果。

## 连续性快照字段

- 人物：屏幕位置、朝向、姿态、表情、服装、手中道具、视线目标。
- 场景：机位、景别、光源方向、色温、天气、入口出口和背景活动。
- 动作：已完成事项、仍在持续的动势、下一段可启动的动作。
- 声音：环境底噪、对白尾音、音乐节拍和转场音效。

## 失败检查

- 后续段是否重新设计了人物或场景。
- 是否只写“继续上一段”而没有复述关键状态。
- 是否在切点同时改变人物、机位、光线、背景和动作。
- 每段是否有新的剧情功能，是否重复上一段。
- 结尾是否有结果和收束，而不是在动作中途突然结束。
