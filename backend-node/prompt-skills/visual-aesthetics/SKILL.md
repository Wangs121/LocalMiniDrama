# 视觉美学设计

负责构图几何、真实光影、材质微观细节、色彩关系、画面层级、角色参考图和关键帧视觉合同。目标不是给所有画面添加“电影感、8K、HDR”，而是建立可持续的视觉系统，让首尾帧和相邻镜头在人物身份、空间、光源、材质与风格上保持一致。

阶段资料：

- `guide.md`：美学决策顺序和连续性合同。
- `美学约束`：全局光照、材质、冷暖对比、极简构图及项目类型配置。
- `关键帧视觉设计`：角色参考图、首帧、尾帧和五层图片提示词结构。
- `参考图驱动运动设计`：从参考图读取可动层、首尾状态、空间拓扑和镜头自由度，把静态画面转成可执行的视频过程。
- `visual-镜头与美学词汇库`：画质、光影、大气、镜头质感和后期收束词汇。
