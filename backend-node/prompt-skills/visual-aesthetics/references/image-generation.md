# 角色参考图与关键帧视觉设计

## 目标

角色参考图负责锁定身份，首帧和尾帧负责锁定视频的视觉状态。它们不是普通插画：必须为后续分镜和视频生成提供可复用、可检查的身份、空间、构图、光线和动作状态。

## 两类图片的职责

### 角色参考图

角色参考图解决“这个人是谁”，不承担具体剧情。

必须明确：

- 年龄感、性别表达、脸型、五官比例、肤色和稳定辨识特征。
- 发型、发色、发长及固定饰品。
- 常用服装的时代、剪裁、材质、颜色和磨损状态。
- 正面、侧面、背面或三分之二侧面的结构一致性。
- 中性站姿、自然表情、均匀光线和不干扰识别的背景。

不要加入：

- 与剧情无关的复杂动作、运镜、粒子和场景特效。
- 会遮挡面部和身体轮廓的强逆光、浓雾或夸张景深。
- 多套互相冲突的服装、年龄或发型。
- 无依据的文字、标志、水印和界面元素。

### 首帧与尾帧

关键帧解决“此刻画面是什么状态”。必须区分动作前和动作后的状态。

首帧包含：

- 动作开始前的人物姿态、手部状态、视线和表情。
- 人物左右站位、前后层次、朝向和相互距离。
- 道具初始位置、门窗状态、环境运动的初始相位。
- 镜头景别、机位、焦段感、构图和光源方向。
- 为运镜与人物动作预留的画面空间。

尾帧包含：

- 动作完成后的可见结果，不是动作过程的模糊描述。
- 与首帧相同的人物身份、服装、场景时代和核心空间结构。
- 因动作合理变化的站位、姿态、表情、道具和景别。
- 与下一镜头衔接所需的视线、出口、动势或声音暗示。

## 五层图片提示词结构

### 1. 镜头与构图

写明景别、相机高度、水平/垂直观察角度、焦段感、画幅和构图几何。不要只写“电影感构图”。

示例：

```text
中景，视线高度机位，三分之二侧面观察，标准焦段感，人物分别位于左右三分线，桌面形成横向空间轴，竖屏画幅，上方和人物运动方向保留呼吸空间
```

### 2. 主体与空间关系

按“人物—道具—环境”顺序写。每个人物都要有身份引用、屏幕位置、朝向、姿态、手部、视线和表情。多人场景必须写相互关系。

```text
角色 A 位于画面左侧，身体朝右，右手压住桌面文件，视线锁定角色 B；角色 B 位于画面右侧稍后方，身体朝左，双手自然垂下，保持警惕；文件位于桌面中央偏左
```

### 3. 光线

至少写清主光方向、光质、色温、明暗关系和背景层次。复杂场景可使用三层光：

- 主光塑造主体体积和情绪。
- 环境光说明空间时间与色温。
- 轮廓光或局部实景光分离主体与背景。

光线必须服从场景来源。例如窗光应有方向，霓虹应在环境中有对应光源，不能同时出现互相矛盾的正面光和强背光。

### 4. 材质与画面层级

写可见、可渲染的材质特征：粗糙度、反射、透光、磨损、湿度、颗粒、织物纹理和表面缺陷。按前景、中景、背景组织信息，避免所有物体同样锐利。

材质描述必须与时代和用途相符。不要把所有道具都写成崭新、镜面、高亮，也不要为了“高级感”无依据地加入大理石、金属或玻璃。

### 5. 风格与质量锚点

最后统一写项目既有的风格、色彩、对比度、镜头质感和清晰度。只使用与项目一致的核心词，不要混合互斥风格。

## 运镜呼吸空间

关键帧不是把画面锁死。根据声明的运镜预留合理变化空间：

- 推近：首帧保留主体周围空间，尾帧允许更紧但身份和轴线不变。
- 拉远：首帧可较紧，尾帧需要可揭示的环境层次。
- 横移/摇摄：主体运动方向前方留空间，背景提供可读的横向层次。
- 跟拍：首帧保留出发方向和落脚区域，尾帧记录新的空间位置。
- 环绕：只在主体和环境有足够三维信息时使用，近景人物避免大角度高速环绕。

## 首尾帧冲突检查

输出前逐项比较：

- 是否仍是同一角色、同一服装和同一场景时代。
- 左右站位变化是否由动作过程解释。
- 道具是否从初始位置到达合理终点，是否突然新增或消失。
- 光源方向和色温是否连续，变化是否有时间或环境依据。
- 首帧与尾帧景别差异是否匹配运镜，而不是无理由换机位。
- 尾帧是否真的显示动作结果，而不是重复首帧。
- 是否存在分屏、拼贴、网格、字幕、标志或画中画误生成风险。

## 角色参考图模板

```text
[角色身份与稳定外貌锚点]，[发型与固定饰品]，[服装时代、剪裁、颜色和材质]，中性自然站姿，正面与三分之二侧面结构一致，手部完整可见，均匀柔和光线，背景简洁，不加入剧情动作与无关道具，真实人体比例，面部结构稳定，材质细节清晰
```

## 首帧模板

```text
[景别、机位、焦段感、构图和画幅]，[场景、时间和空间层次]，[每个角色的身份引用、左右站位、朝向、初始姿态、手部、视线和表情]，[道具初始位置]，[主光方向、环境光与色温]，[材质与前中后景层级]，[为动作和运镜预留的空间]，[项目风格与质量锚点]
```

## 尾帧模板

```text
保持首帧的角色身份、服装、场景时代、轴线和光源逻辑，[动作完成后每个角色的最终站位、姿态、手部、视线和表情]，[道具最终位置与环境变化]，[由运镜导致的合理景别与构图变化]，[可见结果与下一镜头衔接出口]，[项目风格与质量锚点]
```

## 质量检查

- 主体数量、角色名单和参考素材是否准确。
- 角色是否具有稳定身份锚点，而不是只有“漂亮”“帅气”等泛化词。
- 画面是否有明确空间合同和真实物体尺度。
- 首尾状态是否可由一个连续动作过程连接。
- 光线、材质、色彩和画幅是否与项目一致。
- 是否删除了与执行无关的修辞和互相冲突的镜头词。
