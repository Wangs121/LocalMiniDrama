# 参考图与首尾帧驱动的视频运动设计

这套方法用于把单张参考图、首帧、尾帧或多张视觉参考转成可执行的视频过程。核心不是复述图片中“有什么”，而是明确哪些事实必须锁定、哪些层允许变化、变化如何发生、最终停在哪里。参考图提供的是视觉合同，视频提示词提供的是状态转换。

## 1. 先判定参考素材的职责

不要让一张素材同时承担互相冲突的职责。对每张图先标注一种主职责，必要时再标注一种次职责：

- 身份参考：脸型、五官比例、年龄感、发型、体型、服装和标志性配饰。
- 场景参考：空间结构、家具位置、出入口、地平线、背景层级和主光方向。
- 风格参考：媒介、色彩关系、对比度、颗粒、材质处理和后期质感。
- 构图参考：景别、机位高度、主体画面位置、留白和视觉重心。
- 状态锚点：某一时刻的人物姿态、道具状态、光线状态和动作阶段。

同一细节在不同参考之间冲突时，按项目事实与显式素材职责解决，不把冲突留给模型猜测。例如身份图负责服装，首帧负责姿态，场景图负责空间，不应让场景图里偶然出现的陌生人物覆盖主角身份。

## 2. 单图读图的七个维度

### 2.1 主体身份

记录不会随动作变化的稳定特征：脸部结构、发色发型、服装剪裁、面料、配饰位置、身体比例。只描述可辨认的关键点，不堆叠泛化审美词。

### 2.2 初始姿态

把姿态拆成头、视线、肩、躯干、双手、重心和双脚。动作从这里开始，不能让人物在第一瞬间无因跳到另一姿态。

### 2.3 空间拓扑

记录主体与地面、墙面、桌椅、门窗、前景遮挡和背景标志物的相对关系。使用“左前方一臂距离”“人物身后两米的门框”“前景右下角虚化杯子”这类关系，而不是只有物品清单。

### 2.4 光照逻辑

确认主光方向、色温、软硬、环境反射和阴影方向。运动过程中人物转身或相机换位时，光源可以改变在脸上的作用，但光源本身不能无因跳到另一侧。

### 2.5 材质与可变形性

区分刚体、软体、流体、粒子和有生命主体。玻璃杯应保持刚性，衣摆和头发可以滞后摆动，烟雾可扩散，液体受重力和容器约束。把运动分配给合适的材质层。

### 2.6 画面层级

分成前景、主体层、中景和背景。确定哪些层静止，哪些层产生视差，哪些层只做微动。真实的运动通常来自层间速度差，而不是所有元素一起漂移。

### 2.7 可用运动空间

检查主体四周是否有足够留白供动作或运镜展开。近景人物贴边时不要安排大幅横移；狭窄室内不要写无法实现的大半径环绕；背景信息不足时不要要求大幅拉远凭空生成完整世界。

## 3. 找到“最有戏的可动元素”

单图转视频不是让全部元素同时动。先选一个主变化，再选最多两个辅助变化：

- 主变化负责叙事结果，例如人物从迟疑到下定决心、门被推开、产品结构展开。
- 辅助变化增强真实感，例如呼吸、眨眼、衣摆滞后、窗帘轻动、光斑移动。
- 环境变化只在有因果时发生，例如列车驶过带来反光扫过，而不是无缘由变色。

主变化应能用“初态 -> 触发 -> 过程 -> 结果”表达。若只能写成“人物自然地动起来，镜头电影感运镜”，说明尚未完成设计。

## 4. 两种基础范式

### 4.1 反应与转折

适合图片本身含有冲突、发现、决定、惊讶或动作蓄势。过程至少包含：

1. 初始状态维持片刻，让观众读懂画面。
2. 明确触发事件进入画面或声音空间。
3. 眼神先反应，头肩和重心随后变化。
4. 主动作发生并产生可见结果。
5. 镜头在结果最清楚的位置停止。

避免人物从静止直接跳到夸张表情。细微反应应遵守身体传播顺序：视线 -> 头部 -> 肩颈 -> 躯干 -> 手脚。

### 4.2 凝视与自然观察

适合日常瞬间、肖像、环境氛围、产品观察或不需要戏剧转折的镜头。过程依靠持续微动和注意力转移，而不是硬塞剧情：

- 呼吸引起肩颈和衣料的极轻变化。
- 眼神在一个明确目标与远处之间移动。
- 手指、头发、衣摆或环境物产生低幅辅助运动。
- 相机只做一种缓慢、可解释的观察运动。
- 结尾停在比开头多一层信息的构图上。

凝视不等于静止。完全没有内部运动会像照片推拉；运动过多又会破坏身份和构图。优先采用低幅、不同步、有因果的微动。

## 5. 首帧与尾帧是状态方程

有首尾帧时，先分别建立状态表，再设计中间过程。

| 状态维度 | 首帧 | 尾帧 | 中间必须解释什么 |
|---|---|---|---|
| 人物位置 | 起始坐标与朝向 | 结束坐标与朝向 | 位移路径、转向顺序、遮挡关系 |
| 姿态动作 | 关节与重心初态 | 关节与重心终态 | 动作分解、惯性、停顿和落点 |
| 道具 | 所属者、位置、开合状态 | 最终归属与状态 | 谁接触、如何受力、如何到达 |
| 相机 | 景别、机位、方位 | 终点构图 | 相机轨迹、焦点转移、停止位置 |
| 光影 | 主光和阴影方向 | 最终光照 | 时间变化或光源运动的原因 |
| 环境 | 结构与可见标志物 | 最终结构 | 哪些区域因运镜出现，哪些保持不变 |

### 5.1 先验证可达性

以下情况意味着首尾状态难以在一个片段内稳定连接：

- 人物身份、服装或发型无剧情依据地改变。
- 相机从室内近景跳到远距离航拍，且没有可行连续路径。
- 道具从一个人手中瞬移到另一位置。
- 光照方向、时间或天气完全相反，却没有转场机制。
- 短时间内同时要求复杂表演、大幅运镜、场景变换和特效变形。

遇到不可达状态，优先降低中间复杂度、使用遮挡或匹配剪辑、拆成多个镜头，不能用更多形容词掩盖矛盾。

### 5.2 中间过程采用关键状态

不要逐帧穷举。选择 2 至 4 个真正决定结果的关键状态：

- 起势：从首帧姿态自然解锁。
- 发展：主体完成主要位移或动作，镜头开始服务它。
- 转折：方向、注意力或空间信息发生一次明确变化。
- 落点：动作减速，回到尾帧规定的构图和状态。

每个关键状态只承担一个主要变化。若同一状态中人物转身、相机环绕、背景爆炸、服装变形同时发生，应拆分或删减。

### 5.3 尾帧落点必须可见

最后一句要描述画面结果，而不是“最后与尾帧一致”。明确主体在画面中的位置、姿态、视线、道具状态、相机景别和停止方式。尾帧不是风格参考，而是运动必须抵达的目标状态。

## 6. 相机运动与主体运动的分工

相机和主体不应争夺同一个变化轴：

- 主体向镜头走近时，相机可轻微后退保持景别，或静止让主体自然变大；不要再高速推近。
- 主体横向穿过空间时，相机可跟随保持位置，或静止让其完成横穿；不要同时反向甩镜。
- 主体原地完成细腻表演时，相机可缓慢推近强化情绪。
- 相机大幅揭示环境时，主体动作应简化为稳定、易保持的行为。

一段视频通常只需要一个主要摄影机意图：发现、跟随、揭示、压迫、孤立或收束。先写意图，再选择运动，不把推拉摇移升降环绕当作装饰清单。

## 7. 多层运动与视差

真实镜头的空间感来自不同深度层以不同速度移动：

- 横移时前景最快、主体适中、远景最慢。
- 推近时主体和近景尺寸变化明显，远景变化较小。
- 环绕时前后遮挡顺序连续变化，背景不能像平面贴图跟着主体旋转。
- 手持观察可有低幅不规则漂移，但地平线和建筑垂直线仍需整体稳定。

提示词应明确一到两个可验证的视差结果，例如“前景门框从画面右侧滑出，人物保持中央，后方走廊缓慢展开”，比只写“电影感横移”更可执行。

## 8. 人物与物理稳定性

### 8.1 身份保护

近景人物避免高速环绕、突然变焦和大角度转头同时发生。脸部越重要，运动越应缓慢、单纯、正面可见。遮挡经过面部时要短且有明确来源，不能让遮挡成为换脸机会。

### 8.2 手部与道具

涉及拿取、递交、开合或倾倒时，写清：初始接触点、发力手、另一只手的职责、道具路径和最终支撑点。避免同一只手同时完成两个动作，避免道具在遮挡后无因改变形态。

### 8.3 衣料、头发和粒子

软体运动应滞后于身体或风源，幅度逐渐衰减。头发、衣摆、烟雾、尘埃全部大幅运动会造成画面沸腾；只选与风向和主体运动一致的层。

## 9. 风格连续性不是形容词重复

锁定画风应使用可观察属性：

- 媒介：实拍、二维绘制、定格、三维渲染或混合媒介。
- 光线：光源位置、硬度、色温、光比和环境反射。
- 色彩：主色、辅助色、饱和度范围、黑位和高光倾向。
- 材质：皮肤、布料、金属、玻璃、木材等的微观表现。
- 镜头：焦段感、景深、畸变、颗粒和运动稳定度。

视频全过程保持这些属性的因果一致。不要同时要求纪实手持、广告级无瑕棚拍、极浅景深和高速复杂运镜，除非项目明确设计了风格转折。

## 10. 可执行提示词骨架

在当前任务既有输出协议内，视频段落可按下列语义顺序组织：

1. 视觉合同：身份、服装、场景结构、媒介和主光保持什么。
2. 首帧状态：人物姿态、视线、道具、相机和画面位置。
3. 触发与主动作：谁因为什么开始变化。
4. 相机响应：起点、轨迹、速度变化、主体画面位置变化。
5. 关键状态：动作经过哪些必要阶段，物理结果是什么。
6. 尾帧落点：最终姿态、空间关系、景别和停止方式。
7. 稳定约束：只写与本镜头风险直接相关的身份、空间、肢体和材质保护。

示意：

```
保持角色身份、服装纹理、房间结构和左侧窗光不变。开场人物位于画面右三分之一，
右手扶桌，视线落在桌面信封上。门外脚步声触发她先抬眼、再缓慢转头，重心仍留在
桌边；镜头从中近景低速推近，人物由右三分之一移动到画面中央，背景门框逐渐出画。
她用左手拿起信封，在胸前停住，呼吸收紧。结尾抵达规定尾帧：正面近景、信封完整
可见、视线朝门口，相机缓入停止。手指数量、脸部比例、桌面和窗光方向稳定。
```

## 11. 失败模式与修复

### 视频只像图片缩放

原因通常是只写运镜，没有内部事件。加入一个明确触发、一个主体动作和一个可见结果，同时保留低幅环境微动。

### 与首尾帧关系弱

原因通常是把首尾帧仅当风格参考。改用状态表，明确首态、关键中间态、尾态以及相机如何抵达终点。

### 中途换脸或换装

减少近景大角度旋转和遮挡，锁定少量高辨识身份特征，降低同时发生的动作数量；不要用长串泛化否定词代替具体身份合同。

### 背景结构漂移

指定两个到三个固定空间锚点及其遮挡顺序，缩小运镜范围，写清新露出的区域来自哪一方向。

### 动作机械或突然

补充触发、预备动作、重心转移、惯性和减速落点。删掉互相抢节奏的辅助动作。

### 画风中途改变

检查是否混入互相冲突的媒介、光线或后期词；保留一套主视觉合同，并让风格变化只在剧情明确要求时发生。

## 12. 生成前检查

- 是否明确每张参考素材的职责，而不是笼统“参考所有内容”？
- 是否写清首帧的身体、道具、空间和相机状态？
- 是否只有一个主变化，辅助变化不超过两个？
- 是否说明触发、过程、物理结果和尾帧落点？
- 相机是否有起点、运动方式、主体位置变化和停止位置？
- 首尾状态是否在当前片段容量内物理可达？
- 是否锁定人物身份、空间拓扑、光源方向和关键材质？
- 是否避免近景大环绕、三轴同动和无因场景变形？
- 是否保留当前任务既有的素材编号、厂商限制和输出格式？

这套方法来自原始图片驱动路径中对“反应/凝视”“图像框架”“动作分层”“物理常识”和“关键状态”的实践总结，并经过通用化重组。它不规定厂商参数，也不替代项目已有的首尾帧与安全约束。
