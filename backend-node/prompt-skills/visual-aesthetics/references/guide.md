# 视觉美学执行合同

## 决策顺序

1. 先锁定项目事实、时代、人物身份和场景空间。
2. 确定当前镜头的视觉主次：人物、动作结果、道具还是环境。
3. 设计构图和前中后景，让主次可以被一眼读取。
4. 根据真实光源设计主光、环境光和轮廓分离。
5. 为关键材质写粗糙度、反射、透光、磨损和尺度，不给所有物体同样质感。
6. 最后统一色调、对比度、颗粒、画幅和项目风格。

## 构图原则

- 主体位置必须服务视线和运动方向，不能只写“三分法”而没有人物位置。
- 画面层级至少区分前景、中景、背景；景深服务叙事焦点，不是固定套用浅景深。
- 多人场景写清左右、前后、距离、朝向、视线和遮挡关系。
- 为动作与运镜预留呼吸空间，首尾帧可以随运动合理变化但不能无依据换机位。

## 光影与色彩

- 每个主要光源都要有环境来源、方向、光质和色温。
- 冷暖对比用于分离空间、人物或情绪，不把所有暗部染成同一种颜色。
- 光线变化必须有时间、动作或环境依据，并在相邻镜头中连续。
- 夜景保留暗部层次和真实曝光，不默认把人物均匀照亮。

## 材质和真实尺度

- 描述可见的材质响应，而不是泛化的“高级质感”。
- 物体尺寸、人体比例、家具高度和透视必须符合时代与场景。
- 磨损、污渍、湿度和反射只用于有依据的主体，不无差别铺满画面。

## 连续性检查

- 角色身份、服装、发型、场景时代和画幅是否稳定。
- 主光方向、色温、天气和时间是否能从上一镜头自然延续。
- 首尾帧的道具位置和人物姿态是否由动作解释。
- 风格词是否一致，是否混入互斥的写实/动画、柔光/硬光或极简/繁复要求。
