# 创意策略执行合同

## 概念漏斗

1. 用一句话写清人物/主体、目标、阻力和变化。
2. 找出观众第一眼需要理解的异常、悬念、情绪或奇观。
3. 删除与核心变化无关的第二概念和装饰性事件。
4. 为核心变化设计可见结果，而不是只描述氛围。
5. 检查结尾是否形成情绪落点、信息反转、视觉闭环或下一镜悬念。

## Hook 类型

- **目标 Hook**：人物立即面对一个清晰目标或危机。
- **异常 Hook**：正常空间中出现违背预期的物体、动作或关系。
- **结果预告**：先展示部分结果，再让观众追问过程。
- **视听 Hook**：关键声音、突然静默、强动作接点或构图反差。
- **人物 Hook**：微表情、选择或关系张力让观众立即关心角色。

Hook 不能破坏剧本事实，也不能靠无依据的爆炸、变装或新角色制造刺激。

## 信息密度

- 单片段聚焦一个主要戏剧任务，允许多个动作节拍但必须属于同一因果链。
- 对白、动作、运镜和视觉特效争夺同一时间预算；优先保留推动剧情的信息。
- 复杂镜头使用结构化长提示词写全身份、空间、动作、结果和连续性，再删除重复修辞。

## 复看与收束

- 首尾构图或动作形成呼应。
- 第一遍关注主动作，第二遍可发现反应、道具或背景线索。
- 反转必须在前段有视觉依据，不能凭空改变世界规则。
- 结尾给出动作结果和情绪余波，不在最后一刻堆入新概念。
