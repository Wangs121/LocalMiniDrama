# 创作 Skill 视频 A/B 测试清单

本测试在所有自动化检查通过后人工执行。A/B 两次生成必须使用同一项目、同一分镜、同一首帧和尾帧、同一模型、同一随机种子与视频参数，只改变 Skill 选择。执行测试会消耗模型额度。

## 固定样本

- 场景：夜间室内，两名角色隔桌对峙，人物站位和光源方向明确。
- 初始状态：角色 A 位于画面左侧，右手压住桌面文件；角色 B 位于右侧，保持警惕。
- 动作：角色 A 推出文件，角色 B 低头确认后抬眼回应。
- 结果：文件停在角色 B 面前，两人视线重新交汇。
- 首尾帧：首帧锁定初始站位，尾帧锁定文件位置、视线结果和人物身份。
- 建议时长：使用当前模型与适配层支持的相同时长，不在 Skill 中写厂商时长限制。

## A 组：禁用 Skill

1. 在项目 Skill 设置选择“全部禁用”，或请求中显式传入 `prompt_skill_ids: []`。
2. 生成并保存最终视频提示词审计记录。
3. 确认审计中的 `selection_source` 为 `request` 或 `project`，`requested_ids` 和 `skills` 均为空。
4. 审核提示词后再提交视频生成。

## B 组：推荐组合

1. 显式选择 `cinematic-camera`、`storyboard-planning`、`editing-rhythm` 和 `visual-aesthetics`。
2. 使用与 A 组完全相同的输入和模型参数生成提示词。
3. 确认审计记录包含 Skill ID、版本、阶段、引用章节、字符数和内容哈希。
4. 审核提示词后再提交视频生成。

## 对比指标

- 首帧和尾帧身份、站位、场景时代、道具位置是否保持一致。
- 运镜是否是一条可执行路径，而不是无关镜头术语堆叠。
- 动作是否具有初始状态、过程和可见结果。
- 角色与镜头运动是否保留合理空间，是否出现穿模、瞬移或左右翻转。
- 光线、色调和材质是否连续，是否发生无依据的画风切换。
- 节拍是否匹配动作信息密度，是否存在冗长静止或过快跳切。
- Skill 上下文是否低于 128,000 字符，单引用是否低于 64,000 字符，截断项是否有记录。

## 审核门

在实际调用视频模型前，人工确认两组提示词均未改变角色身份、首尾帧关系、安全规则、素材编号、厂商限制和输出协议。记录模型版本、生成参数、视频任务 ID 与主观评分，但不要在日志中记录 API Key 或媒体内容。
